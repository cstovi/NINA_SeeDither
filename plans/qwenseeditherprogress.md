Key Decisions
- PluginBase required: User confirmed need for options panel UI — will implement thin plugin class with settings container and WPF options page, not trigger-only injection
- Absolute GoTo over relative pulses: Bypasses S30 driver bug (drops RA axis) and mechanical backlash (swallows small pulses); uses max speed + encoder verification for guaranteed displacement
- Independent RA/Dec randomization every exposure: Breaks walking noise patterns better than quadrant-based dithering
- Plate scale defaults to 2.39 arcsec/pixel (S30), with user override field and placeholders for S50/S30 Pro

Critical Context
- S30 Hardware: IMX462 sensor, 2.9µm pixels, 250mm focal length → ~2.39 arcsec/pixel image scale; heavy Dec drift from polar alignment error; RA tracking stable but guide pulses fail
- Alpaca Driver Bug: NINA's direct guider command drops the RA axis component on S30 mounts
- Mechanical Backlash: Azimuth/RA gear train has significant slop; pulses <~5s swallowed without moving optical tube. GoTo commands bypass this by commanding absolute coordinates at max slew speed until encoders confirm position.
- Coordinate Math: RA offset requires cos(Dec) correction to convert arcseconds to time seconds: OffsetRA_sec = (Arcsec / 15) * cos(Dec)
