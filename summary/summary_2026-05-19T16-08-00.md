## Key Decisions
- Dropped `[IsExpression]` approach; `Expression` is internal to NINA
- Use `<nina:SequenceBlockView>` with `SequenceItemContent` and `SequenceItemProgressContent`
- Constructor injection for `ITelescopeMediator` (static `Mediators` was uninitialized)
- Dither from current mount position on each fire, not cached base coordinates
- Plate scale auto-detected from camera name (e.g., `Seestar S30_7c201631 Telephoto Camera` → 3.74"/px)
- `LostFocus` binding for numeric textboxes to avoid UI refresh during typing
- Plate scale precision (3.74 vs 3.99) doesn't matter for dither — only affects pixel display hint
